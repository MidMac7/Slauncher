## 🌐 بخش ۱: راهنمای تنظیم IP، DNS و شبکه گیم‌نت (LAN Setup)

برای اینکه ارتباط بین سرور و کلاینت‌ها بدون هیچ‌گونه قطعی یا تاخیر (Ping < 1ms) برقرار باشد، آی‌پی سیستم‌ها باید به صورت دستی (**Static IP**) تنظیم شود:

### ۱. تنظیمات کارت شبکه سیستم سرور (Server PC):
وارد `Control Panel -> Network and Sharing Center -> Change adapter settings` شوید، روی کارت شبکه (`Ethernet`) راست‌کلیک کرده و در بخش **IPv4 Properties** مقادیر زیر را وارد کنید:
* **IP Address:** `192.168.1.100`
* **Subnet Mask:** `255.255.255.0`
* **Default Gateway:** `192.168.1.1` *(آی‌پی مودم یا روتر شما)*
* **Preferred DNS:** `8.8.8.8` *(و Alternate DNS: `1.1.1.1` یا آی‌پی مودم `192.168.1.1` - توجه داشته باشید که ارتباط داخلی SLauncher نیازی به اینترنت یا DNS ندارد و حتی در زمان قطع بودن اینترنت، شبکه داخلی گیم‌نت کار می‌کند).*

### ۲. تنظیمات کارت شبکه کلاینت‌ها (Client PCs):
برای هر سیستم کلاینت، شماره آخر IP را به ترتیب شماره سیستم قرار دهید و Computer Name ویندوز را هم‌نام سیستم (`PC001`, `PC002`, ...) بگذارید:
* **سیستم ۱ (`PC001`):** آی‌پی `192.168.1.101`
* **سیستم ۲ (`PC002`):** آی‌پی `192.168.1.102`
* ...
* **سیستم ۲۰ (`PC020`):** آی‌پی `192.168.1.120`

سپس در فایل `client_config.json` کنار برنامه کلاینت، تنها یک‌بار آی‌پی سرور را ست کنید:
```json
{
    "server_ip": "192.168.1.100",
    "server_port": 5050,
    "station_name": "AUTO",
    "kill_explorer_in_kiosk": true
}
